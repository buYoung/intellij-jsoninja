# 고급 설정

기본 생성에 필요하지 않은 상세 제어를 접어 두면서, 필요한 사용자는 같은 화면에서 접근하게 한다. 기준은 [무작위 뷰의 `collapsibleGroup`](../../../src/main/kotlin/com/livteam/jsoninja/ui/dialog/generateJson/random/GenerateRandomJsonTabView.kt#L158)다.

## 구성

펼침 제목 아래에 시드 유지 체크박스, 기능 설명, 키·구조 시드와 새 구조 버튼, 값 시드와 새 값 버튼, 구조 공유·재현 조건 설명을 둔다. 제목은 영역의 이름이고 체크박스는 기능의 사용 여부다.

## 상태와 변형

| 상태 | 영역 | 입력·보조 버튼 | 생성 의미 |
| --- | --- | --- | --- |
| 새 세션의 기본 상태 | 접힘 | 숨김 | 생성 시 두 시드를 새로 선택 |
| 펼침 + 시드 유지 꺼짐 | 표시 | 시드 행 비활성 | 상세 기능을 살펴볼 수 있으나 입력한 시드를 사용하지 않음 |
| 펼침 + 시드 유지 켜짐 | 표시 | 시드 행 활성 | 입력한 두 시드를 사용 |
| 접힘 + 시드 유지 켜짐 | 숨김 | 사용 여부는 유지 | 접는 동작만으로 기능이 꺼지지 않음 |
| 시드 유지 켜짐 + 잘못된 입력 | 검증 시 펼침 요청 | 오류 필드 연결 | 수정 전 유효한 설정으로 취급하지 않음 |

초기 펼침 여부는 `shouldKeepRandomSeeds`를 따른다. 이후 펼침 상태와 체크박스 상태는 별개다. 시드 유지가 켜져 있으면 접어도 요약에 “시드 유지”가 남는다.

## 크기와 토큰 연결

시드 입력은 [확인된 문자 열 폭](../tokens.md)을 사용한다. 펼치면 컴포넌트의 선호 높이가 증가하고, 접으면 돌아간다. 다이얼로그는 [창 크기 규칙](task-dialog.md)에 따라 폭을 유지하며 높이를 조정한다. 고정된 펼침 높이나 애니메이션 시간은 지정하지 않는다.

## 동작

- **새 구조**: 구조 시드와 값 시드를 모두 새로 만든다.
- **새 값**: 값 시드만 새로 만든다.
- **시드 유지 해제**: 입력한 시드를 생성에 사용하지 않고, 그 입력의 정수 검증도 생성을 막지 않는다.
- **다이얼로그 검증**: 잘못된 시드를 발견하면 `setAdvancedOptionsExpanded(true)`를 요청하고 해당 필드의 오류를 반환한다.

접는 동작은 입력 내용을 초기화하지 않는다. 위 동작은 [뷰](../../../src/main/kotlin/com/livteam/jsoninja/ui/dialog/generateJson/random/GenerateRandomJsonTabView.kt#L177), [프레젠터 검증](../../../src/main/kotlin/com/livteam/jsoninja/ui/dialog/generateJson/random/GenerateRandomJsonTabPresenter.kt#L86), [세션 서비스](../../../src/main/kotlin/com/livteam/jsoninja/services/random/RandomJsonGenerationSessionService.kt#L13)에 연결된다.

## 문구와 조합

시드 유지의 목적과 재현 조건은 [문구 기준](../content.md)을 따른다. 하단 요약에는 기능 활성 여부를 표시하되 긴 시드 숫자 두 개를 다시 늘어놓지 않는다. 정확한 숫자는 원래 입력에서 확인한다.

이 패턴을 다른 작업에 적용할 때도 “더 자세히 보기”와 “기능 사용”을 분리한다. 펼침 제목에 체크박스의 의미를 함께 실어 사용자가 두 상태를 혼동하게 만들지 않는다.

## 접근성과 사용 제한

펼침 제목과 체크박스에 각각 키보드로 접근할 수 있어야 하며, 활성 상태가 보조 기술에 전달돼야 한다. 잘못된 필드가 접혀 있어 수정할 수 없는 상태로 남겨 두지 않는다. [접근성 정본](../accessibility.md).

기본 작업의 필수 입력, 결과를 교체하는 대상 안내, 정상 작업에 필요한 오류 해결 정보를 상시 고급 영역 뒤로 숨기지 않는다. 현재 시드 검증처럼 필요한 경우 해당 영역을 드러내는 연결이 있어야 한다.

**실제 확인:** 기존 테스트는 가시성·선호 높이·활성 상태·접은 뒤 값 보존을 검사했다. 화면 읽기 프로그램과 실제 창의 펼침 조작은 미검증이다.
